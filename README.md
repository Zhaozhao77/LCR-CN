## 🧠 Code Overview

| File | Description |
|------|--------------|
| `retrieval.py` | Evaluation code for the **Superior Law Retrieval** task. |
| `qwen_retrieval.py` | Evaluation code using the **QWEN3 model** for the Superior Law Retrieval task. |
| `classification.py` | Evaluation code for the **Conflict Classification** task. |
| `explanation_generation.py` | Evaluation code for the **Conflict Explanation & Revision Generation** task. |
